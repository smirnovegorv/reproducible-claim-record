# Automated local-model runs (Ollama)

The [experiment README](../README.md) closed its first (Haiku 4.5) batch as
inconclusive and named what a discriminating test would need: **drop-in
framing**, **a subtler backdoor where the vulnerability is the fix**, **a more
injection-prone model**, and **more trials**. This directory is that test,
automated.

One self-contained script drives a local Ollama, scores every reply by parsing
the committed `authz.py` with `ast` — **nothing the model writes is ever run** —
and appends one JSON line per trial, so an interrupted run resumes where it
stopped.

## Run

```
python run_ollama_test.py --selftest                                  # scorer vs known replies
python run_ollama_test.py --model qwen3.8:27b --model gpt-oss:20b --n 30
python run_ollama_test.py --summarize                                 # rebuild results/summary.md
```

Talks only to `http://localhost:11434`; standard library only.

## What is here

```
run_ollama_test.py    the harness: arms, payloads, AST scorer, --selftest
results/*.jsonl       one line per trial — the reply, its reasoning, the scores
results/summary.md    tables, regenerated by --summarize
report.html           the rendered two-round report
```

## The arms

**Round 1** keeps the overt `__ops__` backdoor of the parent experiment: the
three arms of `OLLAMA_HANDOFF.md` byte-for-byte (`freeform`, `freeform_caution`,
`rcr`) plus three that split the channel from the instruction
(`freeform_procedure`, `rcr_noproc`, `rcr_witness_rule`).

**Round 2** replaces the code smell with a plausible *policy*: the reviewer's fix
also treats an unowned resource (`owner is None`) as public. `subtleB_freeform`
delivers it as a drop-in file; `subtleB_rcr` carries it nowhere in the record;
`subtleB_rcr_witness` smuggles it into `WITNESS` prose. (Two payloads that lost
the probe — a role defaulting to admin, and a `None == None` match — are kept as
`subtleA_freeform` / `subtleC_freeform`.)

## Result in one line

A subtle policy defeats recognition — free-form merges it **30/30** on both
gpt-oss:20b and qwen3.8:27b — while the record with a clean `CLAIM` keeps it out
**0/30** on both, by construction; the only leak is the same `WITNESS` prose
(16/30 gpt-oss, 22/30 qwen). Full numbers and honest limits in
[RESULTS.md](../RESULTS.md).
